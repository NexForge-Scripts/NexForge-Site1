Politique de confidentialité

Dernière mise à jour : 16 juin 2026

Chez NexForge Scripts, nous accordons de l'importance à votre vie privée. Cette politique de confidentialité explique quelles informations sont collectées lorsque vous visitez notre site web ou utilisez notre formulaire de contact, comment elles sont utilisées et vos droits.

1. Informations collectées

Notre site web ne collecte des données personnelles que dans les situations suivantes :

  • Formulaire de contact : Lorsque vous nous envoyez votre adresse e-mail et votre message, ces informations sont utilisées uniquement pour vous répondre.
  • Journaux serveur : Notre serveur web peut enregistrer des données techniques standard telles que l'adresse IP, le type de navigateur et les pages visitées. Ces données ne permettent pas de vous identifier personnellement.

2. Utilisation de vos données

Les informations collectées sont uniquement utilisées aux fins suivantes :

  • Répondre aux demandes soumises via le formulaire de contact
  • Améliorer le site web et l'expérience utilisateur
  • Respecter les obligations légales

Votre adresse e-mail et votre message ne sont jamais partagés, vendus ou loués à des tiers.

3. Stockage des données

Les messages du formulaire de contact sont transmis via Formspree et redirigés vers notre boîte de réception. Les messages sont conservés aussi longtemps que nécessaire à des fins de communication. Ils peuvent être supprimés sur demande.

4. Cookies

Ce site web n'utilise pas de cookies. Aucun cookie de suivi, d'analyse ou de publicité n'est présent.

5. Liens tiers

Notre site contient des liens vers des services tiers comme GitHub, Discord et Buy Me a Coffee. Ces sites ont leurs propres politiques de confidentialité, et NexForge Scripts n'est pas responsable de leurs pratiques de traitement des données.

6. Sécurité des données

Nous prenons des mesures techniques et administratives raisonnables pour protéger vos données personnelles. Notre site est servi via HTTPS et les données du formulaire de contact sont transmises de manière cryptée.

7. Vos droits

Vous disposez des droits suivants concernant vos données :

  • Demander l'accès aux données que nous détenons sur vous
  • Demander la correction de données inexactes
  • Demander la suppression de vos données
  • Vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à nexforgescripts@gmail.com.

8. Contact

Si vous avez des questions concernant cette politique de confidentialité :

E-mail : nexforgescripts@gmail.com

9. Modifications

Cette politique de confidentialité peut être mise à jour si nécessaire. Les modifications prennent effet dès leur publication sur cette page.
